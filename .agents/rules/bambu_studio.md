# Bambu Studio Knowledge
**German UI Translations & Tips:**
- The setting "Avoid crossing walls" (crucial for reducing stringing, especially with TPU) is translated as **"Vermeiden von Wandüberquerungen"** in the German version of Bambu Studio.
- It is located under the "Quality" (Qualität) -> "Advanced" (Erweitert) section.
- If the user asks for Bambu Studio settings to fix stringing with TPU, always recommend turning on "Vermeiden von Wandüberquerungen" and use the exact German terminology.
