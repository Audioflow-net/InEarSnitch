# Terminal Path Rule
WICHTIG: Wenn du dem User einen Terminal-Befehl zum Ausführen vorschlägst (z.B. Python-Skripte starten), musst du IMMER den absoluten Pfad oder einen `cd`-Befehl im Snippet mitgeben (z.B. `cd /Users/ben/Desktop/InEarSnitch && python metrology_lab.py`). Der User darf nie raten müssen, in welchem Verzeichnis er den Befehl ausführen soll.
