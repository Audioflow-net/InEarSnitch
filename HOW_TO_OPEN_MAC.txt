InEar SNITCH – How to Open on macOS
=====================================

Because InEar SNITCH is in beta and built via cloud servers without an official Apple Developer Certificate yet, macOS will falsely claim the app is "damaged" and block you from opening it. 

Here is the exact fix (takes 10 seconds):

──────────────────────────────────────────────────
THE FIX (Using Terminal)
──────────────────────────────────────────────────
1. Drag InEarSnitch.app into your Applications folder
2. Open the "Terminal" app on your Mac (Press CMD+Space, type "Terminal" and hit Enter)
3. Copy and paste the following exact command into the Terminal and press Enter:

xattr -cr /Applications/InEarSnitch.app

4. Done! You can now double-click InEarSnitch in your Applications folder and it will open normally.

──────────────────────────────────────────────────
APP NOT SHOWING UP IN SEARCH? (Spotlight/Launchpad)
──────────────────────────────────────────────────
If you cannot find the app using the macOS Spotlight search or Launchpad after installing:

1. Open Terminal again
2. Paste this command to force macOS to index the app:
   mdimport /Applications/InEarSnitch.app
3. Paste this command to restart the Launchpad:
   killall Dock

If it still doesn't show up, simply launch it manually by going to your Applications folder in Finder and double-clicking "InEarSnitch". You can also drag it from there directly into your Dock.

──────────────────────────────────────────────────
WHY DOES THIS HAPPEN?
──────────────────────────────────────────────────
When you download an app via a web browser, macOS adds a "quarantine" flag. Because the app does not have a paid Apple certificate yet, macOS overreacts to this flag and says the file is "damaged". The terminal command simply removes this web-download quarantine flag.
